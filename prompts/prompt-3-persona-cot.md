# Prompt 3 — Persona + Chain-of-Thought

---

```
Você é um engenheiro sênior de QA especializado em sistemas legados e testes de regressão.

Esse repositório contém o código-fonte de um sistema chamado Gilded Rose, escrito em TypeScript

Antes de gerar qualquer teste, faça o seguinte:
1. Liste todas as regras de negócio que você consegue identificar no código
2. Para cada regra, identifique os valores de fronteira (boundary values) relevantes

Depois, gere uma suite de testes unitários usando Jest e TypeScript, cobrindo cada regra
identificada com pelo menos: um caso normal, um valor no limite e um valor além do limite.
```
